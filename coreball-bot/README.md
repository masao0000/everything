# まち針ゲーム 自動プレイツール (coreball-bot)

[まち針ゲーム (arealme.com/coreball)](https://www.arealme.com/coreball/ja/) を Playwright で自動プレイし、レベルを進めます。

## 使い方

```bash
cd coreball-bot
npm install
npx playwright install chromium   # 初回のみ
node bot.mjs --levels 20          # ブラウザが開き、20 レベル進める
```

| オプション | 既定値 | 説明 |
|---|---|---|
| `--levels N` | 10 | クリアするレベル数 |
| `--retries N` | 3 | 同じレベルで連続失敗してよい回数 |
| `--margin 度` | 1 | 当たり判定に足す安全マージン。大きいほど慎重だが、密集レベルで詰まりやすい |
| `--profile DIR` | `./profile` | ブラウザのプロフィール（進行状況が保存され、次回は続きから） |
| `--headless` | off | 画面を出さずに実行 |
| `--no-block-ads` | – | 広告ブロックを無効化 |

## 自動の ON / OFF

- 画面右上の **「自動: ON (A)」ボタン**をクリック、または **A キー**で切り替えられます。
- OFF の間は自動で撃たず、自分で操作できます（スペースキー / クリックで発射）。
- レベル途中で ON に戻すと、その場から自動で続けます。OFF のままレベルが終わると、ON に戻すまで次のレベルは始まりません。

## しくみ

- `inject.js` をページ読み込み前に注入し、Canvas の描画命令（中心から伸びる線）から針の角度を毎フレーム取得。
- レベル開始時にゲームが渡す回転関数（`config.round`）を複製し、同じ入力（フレーム時間・発射の有無）で再生して、着弾時（約 50ms 後）の角度を正確に予測します。発射で逆回転するレベルや、一定時間で速度が変わるレベルにも対応。
- 着弾点（真下）と既存の針の距離がゲームの当たり判定より大きいときだけスペースキーを送ります。

## 注意

- 個人で楽しむ用途向けです。アカウント連携したランキングへの記録送信には使わないでください（既定ではログインしない新しいプロフィールで動きます）。
- サイト側の更新で動かなくなる可能性があります。
