# 寿司打オフライン（チート付き）

寿司打 (https://sushida.net) のゲーム本体を自分のPCにダウンロードし、ローカルでチート付きで遊ぶためのツールです。

- **個人利用専用です。** ダウンロードしたゲームのファイル（`site/`）はリポジトリに含めず、どこにも公開しないでください（`.gitignore` 済み）。
- ランキングへの送信は遮断しています（`serve.mjs` が外部への通信を CSP で禁止）。チートした記録が本家のランキングに載ることはありません。

## 使い方（ダブルクリックで起動）

1. このリポジトリを ZIP でダウンロードして解凍する
2. `sushida-offline` フォルダの中の起動ファイルをダブルクリックする
   - Windows：`start.bat`
   - Mac：`start.command`
3. ブラウザが自動で開いて寿司打が始まる（http://localhost:8080/）

起動ファイルがやること：

- Node.js が無ければインストールする（Windows のみ。winget を使う。Mac は https://nodejs.org/ja から入れる）
- 初回だけゲーム本体と OCR エンジンを `site/` にダウンロードする（約 30MB）。2回目以降はネット接続なしで動く
- ローカルサーバーを起動してブラウザを開く。黒いウィンドウを閉じると終了する

コマンドで動かす場合：`node download.mjs` のあと `node serve.mjs --open`

## チート機能

右側のチートパネルから操作します。

| 機能 | 内容 |
| --- | --- |
| 自動入力 | ローマ字欄を OCR で読み取り、自動でキーを入力します。1文字ごとの入力間隔（0〜200ms）を調整できます |
| 時間の速さ | ゲーム内時間を 停止 / ×0.25 / ×0.5 / ×1 / ×2 に変えられます。停止中は残り時間が減りません |

ブラウザのコンソールからも操作できます：`sushiCheat.auto = true`、`sushiCheat.speed = 0.5`、`sushiCheat.delay = 30`

## 注意

- ローマ字表示は「設定」で ON のままにしてください。自動入力は画面に出ているローマ字を読み取って入力します。
- 入力できない場合は、ゲーム画面を一度クリックしてください。

## 仕組み

- **ドメインチェック回避**：ゲームは `document.URL` を見て sushida.net で動いているかを確認するので、`cheat.js` でこの値を差し替えています。
- **時間操作**：`performance.now` / `Date.now` / `requestAnimationFrame` を倍率つきの仮想時計に差し替えています。
- **自動入力**：WebGL の画面から吹き出し内の白い文字（まだ打っていない部分）だけを取り出して白黒にし、Tesseract.js で読み取って `keypress` イベントを送ります。打ち終わった文字はグレーになるので、入力を間違えても残りの部分を読み直して続けられます。
